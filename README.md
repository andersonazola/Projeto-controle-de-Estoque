# Sistema de Controle de Estoque ✅

## Descrição
Este é um sistema simples de controle de estoque desenvolvido em Python. O programa permite registrar novos produtos, alterar informações, remover produtos do estoque e listar todos os produtos cadastrados.

O projeto foi estruturado em camadas, seguindo uma organização básica do tipo MVC (Model-View-Controller), para facilitar a manutenção e o entendimento do código.

Linguagem: Python 3.x

## Funcionalidades
- Registrar produtos com nome, preço e quantidade
- Alterar produtos existentes
- Remover produtos do estoque
- Listar todos os produtos cadastrados

## Estrutura do Projeto
- models/: Contém os modelos de dados, como a classe Inventory e Product.
- controllers/: Responsável pela lógica para manipular os dados entre modelos e visões.
- views/: Interface para interação com o usuário.
- main/: Arquivos principais para execução do programa e processamento auxiliar.

## Porque o projeto foi desenvolvido em Inglês ?  
Apesar de estar aprendendo, optei por escrever o código em inglês com ajuda do Tradutor para adquirir experiência com a linguagem padrão da programação no mundo todo.
